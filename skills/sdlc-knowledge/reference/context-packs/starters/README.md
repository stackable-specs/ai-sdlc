# Engineering Standards Starters

Concrete, opinionated starting points for `../02-engineering-standards.md` so an adopter
does not begin from a blank pack. Pick the file for your language, copy its
language-specific content over the "Project-specific" section of
`../02-engineering-standards.md`, and adjust to your team's reality.

- `engineering-standards.typescript.md`
- `engineering-standards.python.md`
- `engineering-standards.go.md`

A starter is a *draft to edit*, not a mandate. The shared principles in
`../02-engineering-standards.md` always apply; these add language-specific specifics.
